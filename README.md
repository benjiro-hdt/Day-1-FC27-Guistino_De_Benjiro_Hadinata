Deskripsi Repository
Secara umum, repository (atau sering disingkat repo) adalah tempat penyimpanan digital terpusat untuk menaruh, mengelola, serta mengatur berbagai berkas, data, atau kode sumber agar mudah diakses, dicari, dan digunakan kembali

Tujuan Repository
Menyediakan akses terbuka (open access) agar hasil penelitian dan dokumentasi proyek mudah ditemukan serta dimanfaatkan masyarakat luas.

Dokumentasi Kegiatan Workshop (Day 1)
1. Rangkuman Materi & Pembelajaran
Pengenalan Repository: Memahami konsep dasar repository sebagai media penyimpanan dan pengelolaan data/kode secara terstruktur.
Proyek Workshop: Peserta diajak untuk membangun sebuah aplikasi web sederhana berupa Student Task Planner.

2. Poin-Poin Penting & Pengetahuan Baru
Memahami fungsi dan penggunaan repository digital dalam pengelolaan proyek.
Penerapan konsep open access untuk membagikan berkas dan hasil proyek secara terakses.
Langkah awal pembangunan aplikasi web Student Task Planner.

4. Pendapat Pribadi (Refleksi Day 1)
Kegiatan workshop pada Day 1 memberikan wawasan yang sangat bermanfaat, terutama dalam memahami pentingnya pengelolaan dokumentasi melalui repository serta pengalaman praktik langsung membuat aplikasi web Student Task Planner.
